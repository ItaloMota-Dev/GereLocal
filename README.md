# GereLocal

Sistema de gerenciamento de estoque e vendas desenvolvido como parte de um projeto de extensão universitária com foco social.

## Sobre o projeto

O GereLocal foi criado com o objetivo de oferecer uma solução simples e direta para o gerenciamento de estoque e vendas de pequenos comércios.

A proposta surgiu a partir da preocupação em tornar esse tipo de sistema mais acessível para pessoas com pouca familiaridade com tecnologia, priorizando uma experiência de uso clara, intuitiva e fácil de compreender.

## Objetivo

Simplificar o gerenciamento de produtos, estoque e vendas, oferecendo uma alternativa direta aos sistemas mais complexos de gestão.

## Tecnologias utilizadas

- JavaScript
- Vite
- React Router
- Sass (SCSS)
- Recharts
